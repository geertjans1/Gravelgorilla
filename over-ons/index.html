Zo bouwen we een tool

  1. KM 01

    Spitten

    Specs verzamelen, prijzen checken, reviews doorploegen. Elke tool begint met een berg data die we met de hand controleren.

  2. KM 02

    Bouwen

    Van die data maken we een tool die één vraag goed beantwoordt. Geen twintig schermen, maar een paar keuzes die je echt verder helpen.

  3. KM 03

    Testen

    Op telefoon en computer, elke uitkomst nagelopen. Werkt iets niet lekker, dan gaat het terug de werkplaats in.

  4. KM 04

    Bijhouden

    Nieuwe modellen, nieuwe prijzen, nieuwe events: een tool is nooit af. We werken de gegevens bij zodat het advies blijft kloppen.

Meedenken?

Gravel Gorilla groeit op feedback van rijders. Mis je een merk in de kiezer, zie je een prijs die niet klopt of heb je een idee voor een nieuwe tool? Stuur een bericht, dan gaan we ermee aan de slag.
